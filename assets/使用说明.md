# 使用说明

这份文档本身就是一个示例：每一条说明都是一条素材，可以选中、编辑、打标签、拖动、复制。
看完可以随意修改或删除；需要时在「设置」里点「重新生成使用说明」，会再生成一份精简版：全部内容合成一张卡片，只带一个使用说明标签。
说明文字里的 ＃、％％、＝＝ 用的是全角符号，免得被当成真的标签、备注、标记；实际使用时请用半角（英文）符号。

# 基本概念

- [ ] 每一条内容既是素材，也是待办 #说明
  它同时出现在中间栏（素材卡片）和右栏（待办区），用过了就勾掉。
  勾掉的条目会变灰、加删除线，内容不会消失，随时可以取消勾选。
- [ ] 所有内容都保存在普通的 Markdown 文件里 #说明/格式
  数据目录里的每个 .md / .txt 文件就是一个文档，用记事本、Typora、Obsidian 都能打开。
  每条素材是一行任务：「- [ ] 内容」，完成后变成「- [x] 内容」。
  行尾的 ^xxxxxx 是这条的编号，用来在左右两栏对应同一条，请不要删掉；新写的条目会自动补上。
- [x] 已完成的条目长这样：变灰、加删除线 #说明
  顶部勾选「隐藏已完成」可以把它们藏起来。

# 三栏界面

- [ ] 左栏：文档 / 标签 两种看法 #说明/界面
  「文档」列出素材库里的所有文档，点一下只看这个文档的素材。所有文档都放在素材库这一层，没有子文件夹。
  「标签」按标签汇总，点一个标签只看带这个标签的素材；「无标签」是没有标签的素材。
  有子标签的标签前面有个小箭头，点它或双击这个标签可以折叠 / 展开子标签（会记住）。
  块右侧的数字是这一项里未完成的条数。
- [ ] 收件箱、保管箱固定在回收站下面，不能删除也不能改名 #说明/界面
  没有选中文档时，快速添加的内容进收件箱。保管箱可以放长期保留的东西。
- [ ] 新建文档：在左栏「新建文档」框里输入名字，回车或点 ＋ #说明/界面
- [ ] 输入框右键：撤销、重做、剪切、复制、粘贴、全选 #说明/界面
  快速添加、搜索、新建文档、修改标题的输入框都有。标签面板里的输入框没有右键菜单，用 Ctrl+C / V / X / A。
- [ ] 导入文档：把 .md / .txt 文件从资源管理器拖进窗口 #说明/界面
  文件会被复制进素材库（原文件不动），导入后自动选中。拖动时窗口上会显示提示。
  同名时自动改名为「名字 2.md」。
  可以一次拖多个；其他类型或不是 UTF-8 编码的文件会跳过并提示。
- [ ] 不放入TODO：在左栏文档上点右键，勾选「不放入TODO」 #说明/界面
  这个文档的条目就不在右栏 TODO 里显示（中间栏照常显示），左栏里这个文档的名字变淡。再点一次取消。
  适合放资料、长期保存的内容，比如保管箱。
- [ ] 转成卡片：在左栏文档上点右键「转成卡片…」 #说明/界面
  把文档里不是卡片的文字（标题、段落、普通列表）合成一张卡片放在最前面，已有的卡片不变。
  第一行做卡片首行，其余做续行；其他标题改成【标题】，空行去掉。适合导入的 README、笔记这类没有任务行的文档。
  改写前原文件先复制一份进回收站，可以还原。没有可转换的文字时这一项是灰的。
- [ ] 删除文档：在左栏文档上点右键「删除文档…」，确认后移进回收站 #说明/界面
  回收站里可以还原（回到原位置），也可以彻底删除；支持勾选批量删除和清空回收站。
  彻底删除后无法恢复，会先弹框确认。
- [ ] 中间栏：当前文档或分类下的素材卡片 #说明/界面
  卡片只显示第一行，多行内容在末尾显示「…」；双击或右键「编辑」可以看到并修改全部内容。
  卡片下方显示标签；在「全部」或按标签查看时还会显示所在文件。
  标题右边的「按标签显示」：点开列出全部标签，点选筛选卡片，可以选多个（满足任一就显示），再点取消；3 秒没操作自动收起。
  标题最左边的「全部」可以点：不管在哪、筛了什么，点了都显示全部卡片。
- [ ] 右栏：TODO 待办区 #说明/界面
  「手动排序」：还没完成的条目，拖动卡片排序，顺序会被记住。
  「已完成」：勾掉的条目都在这里（不能拖动）；取消勾选就回到「手动排序」。
  顶部的「隐藏已完成」只管中间栏，不影响右栏。不放入TODO 的文档不在右栏显示。
- [ ] 顶部：快速添加、搜索、隐藏已完成、设置、刷新 #说明/界面
  快速添加：输入内容回车保存，可以直接写 ＃标签。左边的「# 标签」按钮可以点选已有标签。
  搜索：只显示包含输入文字的条目（不分大小写）。输入框右边的 × 清空。
  刷新：在外部用别的软件改了文件后，点它重新读取。

# 卡片操作

- [ ] 整张卡片都能操作，包括空白处 #说明/卡片
  单击：选中（中间栏和右栏的同一条都会高亮）
  双击：编辑
  右键：更多操作
  按住拖动：拖到左栏文档上 = 移进那个文档；拖到左栏标签上 = 追加标签（按住 Shift = 替换全部标签）；拖到右栏 = 排序（右栏是「手动排序」时）
- [ ] 完整阅读：点中间栏卡片右边的展开按钮 #说明/卡片
  窗口中央弹出一张小卡片，显示这条的全部内容（单行的也可以点），排版和「阅读原文」一样。
  下面一排快捷操作：复制全部、部分复制、打开 / 复制链接、编辑标签、标记完成。
  点外面、按 Esc 或点 × 关闭。
- [ ] 卡片右键菜单 #说明/卡片
  编辑、复制全部、部分复制、打开 / 复制链接（有网址时）、编辑标签…、标记为已用 / 完成、删除
- [ ] 删除前都会先确认 #说明/卡片
  右键「删除」或选中后按 Delete，会弹出确认框：回车 = 删除，Esc 或点框外 = 取消。
- [ ] 编辑卡片：回车保存，Shift+回车换行，Esc 取消，点到别处自动保存 #说明/卡片
  编辑状态下右键：撤销、重做、剪切、复制、粘贴、全选、忽略复制、复制选中、保存、取消编辑。
- [ ] 多行素材：第二行起缩进写在下面 #说明/格式
  就像这一条：这是第二行，
  这是第三行。缩进的普通列表也属于这一条：
  - 子项一
  - 子项二

# 标签

- [ ] 在内容里写 ＃标签 就是打标签，＃ 后面不要加空格 #说明/标签
  一条可以有多个标签。标签可以分层级，比如 ＃说明/标签 就是「说明」下面的「标签」。
  选中左栏的父标签（比如「说明」）时，所有子标签的素材也会显示出来。
- [ ] 卡片右键「编辑标签…」：加上、去掉、换标签 #说明/标签
  点已有标签就加上，再点就去掉，可以连着点多个；顶部输入框可以新建标签；底部可以清除全部标签。
  已经有子标签的父标签会提示「已有子标签」。
  标签多了：在顶部输入框里打字就只列出名字里含这些字的标签；有子标签的标签前面有箭头，可以折叠 / 展开。
  面板的折叠状态单独记，和左栏互不影响。这份说明的标签都在「说明」下面，默认是折叠的。
- [ ] 在左栏「标签」里选中一个标签后，快速添加的新条目会自动带上这个标签 #说明/标签
  如果你在快速添加里自己写了标签（手打 ＃标签，或用「# 标签」按钮选），就只用你写的，不再自动带上左栏选中的。

# 复制

- [ ] 右键「复制全部」：复制全部正文，不含 ＃标签 和 ％％备注％％ #说明/复制
  多行内容会完整复制。
- [ ] 示例：这一句会被复制 %%这一句是备注，复制时会跳过%% #说明/复制
  把不想被复制的文字写成 ％％备注％％，卡片上显示成灰色。可以在行内，也可以跨好几行。
  不用手打：编辑时选中文字，点「忽略复制」（编辑原文的标题栏），或按 Ctrl+/。再操作一次就是取消。
  备注里的 ＃标签 不算标签。这是 Obsidian 的注释写法，用 Obsidian 打开时备注是隐藏的。
- [ ] 示例：==只复制这一段==，这里不复制，==还有这一段== #说明/复制
  右键「部分复制」只复制 ＝＝标记＝＝ 的内容：同一行的几处用空格连起来，不同行分行。
  不用手打：编辑时选中文字，点「复制选中」（编辑原文的标题栏），或按 Ctrl+E。再操作一次就是取消。
  标记显示成黄色底色；写在 ％％备注％％ 里的标记不算。没有标记时「部分复制」是灰的。

# 网址

- [ ] 示例：Obsidian 官网 https://obsidian.md #说明/网址
  以 http://、https://、www. 开头的文字会显示成链接（下划线）。
  Ctrl+单击网址用浏览器打开；普通单击还是选中卡片。
  右键菜单里有「打开链接」「复制链接」；有多个网址时逐个列出，还有「复制全部链接」。
  写在 ％％备注％％ 里的网址（比如出处）也能从右键菜单打开。

# 编辑原文

- [ ] 「阅读原文」：整篇只读查看，排版更清爽 #说明/原文
  标题去掉 ＃ 并放大，勾选框显示成 □ / ■，行末的 ^编号 不显示，行距更宽。
  正文和界面同一字号；换行时中文标点（，。；：！？）不会出现在行首（编辑卡片、编辑原文时也一样）。
  文字可以拖选复制；网址直接单击就能打开。点「编辑原文」切换到编辑，点「返回」或按 Esc 回到卡片。
  文件被改动（比如在右栏勾掉一条）后会自动刷新。
- [ ] 选中一个文档后，点中间栏顶部的「编辑原文」可以整篇编辑 #说明/原文
  原文会着色：每条开头的勾选框带强调色底色，方便看出每条从哪里开始；＃标签 用标签色；^编号 变淡；
  ％％备注％％ 变灰；＝＝标记＝＝ 黄色底色；网址带下划线，Ctrl+单击打开。
  底部显示行数、字数、素材条数。
- [ ] Ctrl+S 保存，保存后留在编辑区 #说明/原文
  改了还没保存时，标题旁显示「● 未保存」。
  点「返回」、按 Esc、或者点左栏别的地方时，如果有改动会先问：保存（回车）/ 不保存 / 继续编辑（Esc）。
  右键菜单里的「返回（不保存）」直接放弃改动。
- [ ] 「修改标题」可以给文档改名 #说明/原文
  收件箱和保管箱不能改名。

# 键盘

- [ ] 选中卡片后的快捷键 #说明/快捷键
  空格：完成 / 取消完成
  回车：编辑
  Delete：删除（会先确认）
  Esc：取消选中
- [ ] 编辑时的快捷键 #说明/快捷键
  回车：保存（卡片编辑）　Shift+回车：换行
  Ctrl+S：保存（编辑原文）
  Ctrl+/：忽略复制 / 取消　Ctrl+E：复制选中 / 取消
  Ctrl+Z / Ctrl+Y：撤销 / 重做　Ctrl+A：全选
- [ ] Ctrl+单击网址：用浏览器打开 #说明/快捷键

# 外观

- [ ] 顶部「设置」：主题、强调色、字号、小字大小、卡片间距、圆角、左栏块高度、光标闪烁 #说明/外观
  主题有跟随系统、浅色、深色，以及几套配色主题：护眼（偏灰较沉）、樱米（米色底 + 樱粉）、
  薰衣草（淡紫）、深海（深青底、杏色字，深色）、薄荷（薄荷白 + 深蓝）、羊皮纸（羊皮纸色 + 焦橙）。配色主题的边框线条更明显。
  强调色选「默认蓝」时，配色主题会用自己的强调色；选了别的强调色就以选的为准。
  强调色除了预设，还可以点最后的取色按钮，选任意颜色。
  改了立刻生效，自动保存。数值两边的 − / + 每点一下改一个最小步长；「恢复默认」一键还原。
  光标闪烁默认关闭：闪烁时程序会一直重画，关掉后空闲时几乎不占 CPU。
- [ ] 卸载：「设置」最下面的「卸载素卡…」 #说明
  确认后程序退出并删除自己。勾选「同时删除我的数据」（默认不勾）会把素材库移到回收站，需要时可以还原。

# 其他

- [ ] 轻量：空闲时不占 CPU，几千条素材也能流畅滚动 #说明
  卡片只画屏幕上看得见的那些，素材再多也不卡。
- [ ] 素材库默认在用户目录下的 Sucard 文件夹 #说明/格式
  Windows 是 C:\Users\你的用户名\Sucard，macOS 是 /Users/你的用户名/Sucard。
  想放到别处，可以用命令行参数（sucard D:\Sucard）或环境变量 SUCARD_DIR 指定。
  指定的路径就是素材库文件夹本身，名字可以随意起（比如 D:\我的素材），不存在会自动创建。
- [ ] 数据目录里的 .sucard 文件夹存放排序、界面设置和回收站 #说明/格式
  素材库里的子文件夹不会被读取；文件名以 . 开头的不会被当成文档。
  只读取 UTF-8 编码的文件，其他编码的会跳过并提示。
- [ ] 中文显示成方块时：把任意中文字体文件复制到 数据目录/.sucard/font.ttf #说明
